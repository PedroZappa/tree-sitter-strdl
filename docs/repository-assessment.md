# Repository assessment

This document is being built during Phase 1. It currently records the verified functional baseline; it is not yet a complete repository assessment.

## Functional baseline

Captured on 2026-11-25.

| Component | Version or state |
| --- | --- |
| Tree-sitter CLI | 0.27.2, installed at `/opt/homebrew/bin/tree-sitter` |
| Node.js | 26.8.2 |
| npm | 11.19.1 |
| Local `node_modules/` | absent |

The repository's `package.json` declares `tree-sitter-cli` `^0.25.8`, while the available CLI is 0.27.2. This version difference affected generated output.

The query commands establish that both query files compile and execute against `test-local.strdl`. They do not verify capture correctness because `--quiet` suppresses match output.

An attempted explicit scope variant, `tree-sitter query --quiet --grammar-path . --scope source.strdl ...`, failed with `Unknown scope 'source.strdl'`. This appears to be a CLI configuration issue rather than a query failure; it needs a follow-up using the project's supported CLI version.

### Generated artifact changes

`tree-sitter generate` with CLI 0.27.2 changed these committed files:

- `src/parser.c` — the generated header changed from `Automatically @generated by tree-sitter v0.25.8` to `Automatically @generated by tree-sitter`.
- `src/tree_sitter/array.h` — updated to the newer generated helper implementation.

No source grammar change was made. The changes are attributable to regenerating with a newer CLI than the one recorded in `package.json`.

### Resolution

The repository adopted the newer generator path:

- `tree-sitter-cli` is pinned to `0.27.2`.
- Generated artifacts use ABI 15.
- The minimum supported runtime floor is Tree-sitter 0.25.
- Node.js, Python, Rust, Go, and Swift dependency declarations were updated where applicable. Python uses `~=0.25.0` because plain `~=0.25` would permit 0.27 releases.
- Generated artifacts were regenerated with the pinned CLI. A second generation produced byte-identical `src/parser.c`, `src/grammar.json`, `src/node-types.json`, and `src/tree_sitter/array.h`.
- Node.js, Python, and Go binding tests passed; the Swift library build passed; Rust and Swift tests remain unverified for environmental reasons.

See [compatibility.md](compatibility.md) for the version matrix and validation details. Query compilation succeeds, but capture behavior still needs explicit tests.
